❓ How this works
  1. Build one part — describe it below, hit Build it ▶. Tick ✦ author any part to have Claude write the CAD (any shape, not just brackets — needs your API key).
  2. Refine it — plain-English tweaks. Offline mode only knows bracket phrasings (holes / spacing / wall / ribs); tick use Claude for free-form edits.
  3. Fit it — import a reference STL, drag it into place, pick a fit class, hit Fit.
  4. Assemblies — machines are collections of parts. Load one above, click two parts in the 3D view, and Insert ▶ authors a new part that mates both.

LLM actions (✦ author, Insert, refining an authored part) need ANTHROPIC_API_KEY in .env. Everything else runs offline.

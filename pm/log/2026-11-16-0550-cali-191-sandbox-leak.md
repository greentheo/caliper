### 2026-11-16 · CALI-191 (#304) · A sandboxed build removes its own temp folder however it ends; the server sweeps old ones once at start

Every `sandbox.run_script` made a `caliper_sandbox_*` folder in the temp dir and nothing removed it. caliper-reviewer counted 171,673 in #303's review; there are 215,096 on this machine now.

- **A run removes its own folder** in a `finally`: when it succeeds, fails, or times out (`subprocess.run` kills the child first). A caller that passes its own `workdir` keeps it, as it is.
  - A successful run's `step_path` is now `None`. Its STEP was read into the geometry already, and nothing else read it.
- **A failed run's folder is kept only when asked** (`CALIPER_KEEP_SANDBOX=1`), and the log says where. Otherwise the log says the run failed, why, that the error is in its result, and how to keep one next time.
- **A sweep once at server start** (`sandbox.sweep`, in a background thread from `server.serve`, never `create_app`, so a test's app touches no temp dir). It removes the `caliper_sandbox_*` folders whose newest file is over a day old. It never touches one a run in this process is using, nor a fresh one, which may be another process's run.
- **Tests** (9, in test_sandbox_leak; all failed first):
  - no folder left on success, on failure, or on a timeout with the child killed;
  - a failed run's folder kept with the env var set, with its place in the log, and a good run's removed even so;
  - the log's words for a failure;
  - a caller's `workdir` kept;
  - the sweep removing an old folder and keeping a fresh one, a busy one and another prefix's;
  - a folder with a fresh file in it kept;
  - `serve` sweeping and `create_app` not.
- **Mutants:** 11 of 11 caught. One ("the folder's own time only") survived until the test aged the folder after its fresh file. It was the test's gap: a file written in place doesn't touch the folder's time.
- **Found, not changed:** `making.py:170` leaves a `caliper-print-*` folder the same way (17,129 here), and `server.py:435` a `caliper_part_*` one per STL served. Raised for the foreman.
